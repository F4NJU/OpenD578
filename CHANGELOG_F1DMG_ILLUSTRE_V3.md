## Installation

Voir `INSTALLATION_DEBIAN_F1DMG_ILLUSTRE.md`. L’archive peut être décompressée sur la version v2 ou sur le dépôt d’origine. Le script `tools/install_f1dmg_site.py` reste idempotent.

La vérification locale se fait avec des photographies synthétiques. Pour publier les originaux, l’import de l’archive autorisée reste nécessaire sur le PC Debian.
