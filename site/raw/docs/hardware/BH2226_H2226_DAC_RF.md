# ROHM BH2226FV-E2 : CNA 8 sorties, marque H2226

Le composant est marque **`H2226`** et le boitier observe a ete precise comme **SSOP-B16**. Cette combinaison correspond a la reference ROHM **BH2226FV-E2**, un CNA **8 canaux / 8 bits**. L'identification de type et de boitier est donc retenue ; les 16 broches ne sont pas encore suivies jusqu'au GD32 ni aux destinations analogiques. Relever la broche 1 et le marquage complet sur la photo de reference pour figer la revision de PCB.

## 1. Fonction

Ce composant génère huit tensions analogiques par programmation série. Il **n'est pas** le codec audio TLV320 et ne peut pas fournir directement plusieurs watts au haut-parleur. En RF il peut par exemple servir de source de polarisation ou de tensions de commande varicap, mais **aucune sortie DAx n'a encore été suivie** sur cette carte. Le rôle RF est donc une **hypothèse**.

## 2. Broches de reference BH2226FV-E2 (fonction constructeur et pistes a verifier)

| Pin | Nom | Fonction théorique |
| ---: | --- | --- |
| 1 à 8 | DA1…DA8 | Huit sorties analogiques |
| 9 | VCC | Alimentation analogique/logique |
| 10 | RESETB | Réinitialisation active basse |
| 11 | TEST | Entrée de test, ne pas commander arbitrairement |
| 12 | CSB | Sélection active basse |
| 13 | CLK | Horloge série |
| 14 | DI | Entrée données |
| 15 | SO | Sortie série |
| 16 | GND | Masse |

Le format de commande du BH2226FV comporte **12 bits** à déduire exactement du tableau *Serial data input* de sa notice : adresse / commande de canal et valeur de conversion, échantillonnage à l'horloge avec `CSB` bas. **L'ordre précis des champs et l'état de RESETB à l'allumage doivent être repris de la révision constructeur**, sans copier une séquence non mesurée dans une ROM modifiée.

## 3. Comment le GD32 pourrait y accéder

Aucune liaison GPIO ↔ `CLK/DI/CSB/RESETB` **spécifique à ce boîtier** n'est identifiée dans l'analyse actuellement accessible. Le bus `PB3/PB4` observé dans les traces RF et éclairages n'est pas automatiquement celui de ce DAC.

Pour retrouver la routine dans le firmware V1.21 :

1. Rechercher des boucles d'émission **12 bits**, un `CSB` actif bas et des sorties `CLK/DI`.
2. Croiser les écritures GPIO avec les conditions de changement de fréquence, de bande, de niveau de puissance et de calibration.
3. Chercher un tampon de huit canaux et ses valeurs persistées, mais ne pas supposer qu'une table OEM contient les tensions du BH2226 tant qu'un octet de transaction n'a pas été corrélé.
4. Mesurer les huit sorties avec un voltmètre haute impédance pendant des opérations ordinaires, et identifier la destination par continuité hors tension.

## 4. Pour un firmware alternatif

Pilote séparé `bh2226.c`, exigeant des primitives `clock`, `data`, `cs`, `reset` configurables et une table de calibration **issue du poste sauvegardé**. Aucune valeur de tension, séquence de charge, fréquence de conversion ni profil varicap n'est déduite de la seule identification du composant.

**Qualifie :** reference BH2226FV-E2 (marquage et SSOP-B16). **Non qualifies :** tension d'alimentation sur carte, huit affectations DA, usage du SO, CS/CLK/DI, GPIO du GD32 et calibrations usine.

**Source fabricant :** <https://www.rohm.com/products/data-converters/da-converters/bh2226fv-product>. La correspondance marquage / boitier provient de ROHM ; les associations GPIO/fonctions RF restent inconnues.

## 5. Format exact du mot 12 bits ROHM

La notice ROHM distingue **D0..D7** (valeur 8 bits, D0 bit de poids faible) et **D8..D11** (sélection/commande). Valeurs de la table constructeur dans l’ordre D8,D9,D10,D11 (inverser les quatre bits pour le nibble transmis D11…D8) : `0001` → DA1, …, `1000` → DA8 ; `1001` → sortie du mode *power down* ; `0000` → power down ; codes `1100` à `1111` destinés aux fonctions I/O particulières. **Ces derniers ne doivent pas être employés comme commandes DAC usuelles.**

Pour une conversion ordinaire, le mot peut être représenté comme `((canal_1_à_8 & 0xF) << 8) | valeur_8_bits`. Les **12 bits sont envoyés MSB-first**, DATA pris en compte au front montant CLK lorsque CSB est bas, puis l'écriture est validée au retour CSB haut. **La fiche précise une séquence d'initialisation obligatoire après Power On/Reset** : sortie du mode de veille, sélection I/O/DAC, configuration I/O. Cette initialisation doit être qualifiée dans le firmware réel avant d'envoyer le premier réglage.

Une fonction pure `bh2226_build_dac_word` est présente dans `firmware/hal/serial_command_encoders.c`. Elle ne commande **aucun GPIO du poste** et ne contient aucune table de calibration.

Fiche constructeur PDF utilisée pour la table (2015, rev.001) : <https://www.mouser.com/datasheet/2/348/bh2226fv-e-1807393.pdf>
