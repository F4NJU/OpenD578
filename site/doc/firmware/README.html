OpenD578 alternative firmware work area

This directory is reserved for a future standalone firmware for the D578UV PRO GD32. No radio-flashable binary is provided. A build must be kept separate from the hardware simulator and from manufacturer firmware inputs.

Start with the architecture, validation gates and the emulator and Bluetooth driver design, BT01 and BP-02.

Experimental frequency encoder and trace-only bus plan: QA4818N reconstruction, rf/qa4818n_frequency.[ch] and rf/qa4818n_transport.[ch]. These are not board drivers and do not enable TX.

Documentation evolutive - faits materiels, observations OEM et hypotheses distingues. Pas de firmware installable.
